# tiny-judgment-fonts
Various judgment fonts for Project Outfox's "pump" gamemode.

## Install
- Download by clicking on 'Code > Download ZIP' and install it to your OutFox's 'Judgments' folder.
- If you're using this with Infinitesimal/InfiniteWorlds theme, input the command window code or press select, then go to System > Judge Font.
- When done correctly, you're now able to select and use your newly installed judgment fonts!
